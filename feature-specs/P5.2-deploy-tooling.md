# P5.2 — Deploy tooling: one-command repo → live plugin sync

Status: **DRAFT** — design record for the Feature Roadmap board; not yet implemented.
Owner: Devin (implementation) / Hermes (review)

## Goal

Make `committed = live` by one command. The repo (`argos_plugin/`) is canonical, but
the running Hermes loads the **installed copy** (`plugins/hybrid_memory`), which is
not a git repo and is currently synced by hand. The result: drift is real, verified
only manually, and every "it's fixed" claim requires a deploy check (multiple
incidents in Aug 2026 — e.g. the 25/8 RPC-kwarg gap shipped green in the repo while
live was broken). This closes that permanently.

## Current state (verified 28 Aug 2026)

- Repo source of truth: `argos_plugin/`. Live install: `%LOCALAPPDATA%\hermes\plugins\hybrid_memory` (manual file-copy sync).
- Existing script patterns to follow: `scripts/backup_data.py`, `scripts/apply_customizations.py`, `scripts/egress_report.py` (stdlib-only, explicit modes, stable exit codes).
- No deploy/drift tool exists in `scripts/` today.
- Production loads the installed copy — deployed code needs an app/service restart to take effect.

## Design

`scripts/deploy.py` — Python stdlib only, Windows-safe paths, UTF-8.

- `--source DIR` (default: repo `argos_plugin/` relative to the script)
- `--target DIR` (default: resolved from `HERMES_PLUGIN_*` env / `--target`; documented in `--help`)

Modes:

1. **`--check`** (default): compare file sets + sha256 per file; print one line per
   file (`CHANGED` / `NEW` / `REMOVED` / `UNCHANGED`); also report repo `HEAD` vs the
   last-deployed `HEAD` from the state file. Exit 0 = clean, 1 = drift (usable as a
   gate in the self-corpus regression workflow and CI).
2. **copy** (no flag): copy changed + new source files to target; before overwriting,
   write `<file>.bak-<timestamp>` beside the target; after copying, re-hash every
   copied file and verify byte-identity with source; append to `deploy_state.json`
   (timestamp, source `HEAD`, per-file hashes).
3. **`--prune`** (opt-in, never default): remove target files absent from source.
4. **`--restart-service`** (opt-in): restart the memory shared service after copy via
   the existing service control path; without it, print `restart required`.

Hard rules:

- Never delete anything without `--prune`.
- Never follow junctions/symlinks outside the two directories.
- Copy is atomic-ish and verified: a failed verification leaves `.bak` files intact and exits non-zero.

## Acceptance criteria

- [ ] `--check` reports the *known* drift state of the live install accurately (verified against a manual diff)
- [ ] Copy round-trip: installed files byte-identical to source (hash-verified)
- [ ] `deploy_state.json` exists, auditable, and records source `HEAD`
- [ ] `--check` exit codes work as a gate
- [ ] `SYNC_HANDOFF.md` updated to reference `deploy.py` as the only sync path
- [ ] CHANGELOG entry

## Scope guard

Repo → live only. No fork-checkout sync, no upstream sync, no deletion by default.
